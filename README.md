# PrintFlow — Printing Service Management System

**PrintFlow** is a web-based printing service management system developed using **PHP, MySQL, HTML, CSS, and JavaScript**. It simplifies how customers submit printing requests and how print shop administrators manage orders, from document submission to pickup.

The system offers a clean, responsive interface designed to minimize manual data entry. Customers can upload PDF documents, choose printing preferences using simple controls, view an estimated price, and monitor the progress of their orders. Administrators can review requests, manage the printing queue, update order statuses, configure pricing, and record payments.

## Key Features

### Customer
- Secure account registration and login
- PDF document uploads for printing requests
- Easy selection of paper size, color mode, print sides, and number of copies
- Automatic estimated price calculation
- Order history and status tracking
- Order cancellation where permitted

### Administrator
- Dashboard for monitoring printing requests
- Order review and approval
- Printing workflow and status updates
- Printing rate configuration
- Cash payment recording and printable receipts

## Order Workflow

**Pending → Approved → Printing → Ready for Pickup → Completed**

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Database Access:** PDO

## Release 1 Scope

PrintFlow Release 1 focuses on a streamlined **request-to-pickup workflow**, with manual printing and payment recorded at pickup. Direct printer control and online payment processing are not part of this release.
